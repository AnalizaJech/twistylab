Clock, Square-1 and Redi Cube use ThreeJsPuzzleRenderer because cubing.js exposes only 2D rendering for them. Their state remains a cubing.js KPuzzle. All other puzzles use TwistyPlayer. Only the selected adapter mounts a renderer. Special puzzle renderers can register a new adapter here. Face dragging beyond cubing.js native face presses requires a future geometry-specific interaction adapter.

Redi Cube renders 48 oriented stickers on a stylized 20-piece cube, using the labeled cubing.js SVG net to preserve the KPuzzle sticker order. Color changes follow the logical state; it does not simulate the mechanical corner-turning trajectories.
